# Python File Organizer

A simple Python project that automatically organizes files into folders based on their file types.

## Features

- Organizes files into Images, Documents, Audio, Videos, Archives, and Others.
- Supports multiple file extensions.
- Skips folders while organizing.
- Handles duplicate filenames automatically.
- Displays an organization summary.
- Maintains an activity log with timestamps.
- Shows an overview of organized files.
- Provides a Dry Run preview before moving files.
- Validates folder paths and handles invalid inputs.

## Technologies Used

- Python
- Python Standard Library

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

```bash
python organizer.py
```

6. Follow the menu instructions.

## Menu Options

1. Organize Files
2. View Supported File Types
3. View Activity Log
4. Exit
5. View Files Overview
6. Preview File Organization (Dry Run)

## Important Note

Always test the organizer on sample files first. The Dry Run option lets you preview the proposed file movements without moving files.
